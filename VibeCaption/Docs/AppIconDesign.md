# App Icon Design

## Direction
The icon should communicate live bilingual captions with a clean, broadcast-like feel.

## Symbol Concept
- Rounded square base.
- Two caption lines as speech strips.
- Small dual-language indicator bar.
- Accent pulse mark to indicate live translation.

## Palette
- Base: deep navy `#0E1B2E`
- Mid: blue `#1F6FEB`
- Accent: cyan `#35C2FF`
- Highlight: white `#F8FBFF`

## Included Source
- Vector source: `Resources/AppIcon.svg`

## Export Targets
Generate the following from the SVG for macOS iconset:
- 16, 32, 64, 128, 256, 512, 1024 (and @2x variants as needed)
- Package into `.icns` before final notarized distribution build.
